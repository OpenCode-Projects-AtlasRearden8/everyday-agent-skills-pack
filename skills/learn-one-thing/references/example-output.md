# learn-one-thing: worked example output

Input:

```json
{
  "goal": "Python: print the current date to the terminal",
  "minutes": 20,
  "who": "beginner"
}
```

Output:

```text
Goal: Python: print the current date to the terminal (20 min, beginner)

Verdict: this fits today.

The one thing:
- Python: print the current date to the terminal

The plan:
1. Skim (4 min)
   Look for the shape of the thing: where does it start, where does it end?
2. Do (12 min)
   Actually do the thing: Python: print the current date to the terminal
3. Break (2 min)
   Name the moment this plan will realistically die and what to do then
4. Tell (2 min)
   Say back out loud what was learned in one sentence

Where it fits: attach this to something that already happens - after lunch, right after opening the laptop, while the kettle is on.
```

The worked reply then adds the done-line, which only the agent and the
person can judge: "done means the terminal showed today's date, typed
by you, in a file you wrote." Note what the reply does not do: promise
that this makes anyone a programmer, and link five additional courses.
